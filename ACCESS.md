# Repository access

This repository is public. Anyone can read or clone it without a GitHub account or invitation. Users still need their own authorized HubSpot access; downloading this tool does not grant portal access.

| Recipient | Suggested repository role | Purpose |
| --- | --- | --- |
| Anyone using the tool | No invitation needed | Clone, install, and receive updates |
| Contractor developing the tool | Write | Push branches and propose pull requests |
| Internal maintainer | Maintain or Admin as needed | Manage releases and repository settings |

Only contributors who need direct write access require an invitation. An organization owner or repository administrator can invite a specific GitHub username under **Settings → Collaborators and teams → Add people**. Prefer named accounts and repository-scoped access. Remove write access when an engagement ends. Public read access remains available.

Anyone can read the repository's tracked files and history. Keep client configs, CRM exports, record IDs, journals, exception reports, credentials, and browser profiles outside this repository. Share client-specific reports through the client's approved channel.

Customers can start directly from the README. Grant contractor write access only after the owner identifies the recipient and intended role.
